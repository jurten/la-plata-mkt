# Galaxy hero background

The user selected [Galaxy by React Bits](https://reactbits.dev/backgrounds/galaxy) on 2026-11-15 to replace the rejected cursor attraction experiment.

The shader and motion equations are adapted from [David Haz's official source](https://github.com/DavidHDev/react-bits/blob/main/src/content/Backgrounds/Galaxy/Galaxy.jsx), retrieved on 2026-11-15. Its MIT + Commons Clause copyright and license are retained verbatim in [react-bits-galaxy.txt](../public/licenses/react-bits-galaxy.txt). The adaptation is part of this website, with no React runtime or added dependency.

`galaxy.ts` retains the procedural star layers, depth flight, rotation, twinkle, flares, repulsion, introduction and click warp. Changes are the Three.js host, the site's blue-white palette, a fresh page seed, quieter illumination behind desktop text, three mobile layers instead of four, and a target capped at 500,000 pixels. It shares the existing 24fps transmission clock. The subsequent user refinement keeps 42% of star cells. The latest correction restores the original brightness: core glow .015, flare gain .3, opacity .8 and twinkle .3. Static loading/accessibility skies keep the reduced counts of 140 desktop stars / 60 mobile stars with the original brightness range (.09–.43).

The user's subsequent request removes the hero CRT entirely. `alien-scene.ts` caches the model separately against transparency. `signal-pass.ts` composites that model and the Galaxy texture directly, without distortion. The old noise/scanline canvas, RGB splitting, band remapping and periodic head holds are removed; the hidden controller retains only the shared clock, input and visibility state. Sky animation does not redraw the settled model. All targets, materials and geometries are disposed on graphics failure or scene destruction.

The latest correction makes the alien approach from small to large: `galaxyArrivalScale` maps the opening flight's reveal to 38% → 100% with cubic deceleration. The composite scales around the final head-frame center, so camera autofitting does not cancel the entrance. Pause, offscreen and hidden states freeze that shared progress; resize, pointer input and later click warps do not replay it.

The animated stars also illuminate the head. A second cached target stores view-space mesh normals, updated only when the model image changes. The final composite samples diffuse sky radiance along those normals and reflected radiance along their reflected viewing direction. Sky mipmaps soften light on matte skin while dark eye lenses keep sharper reflections. This is a bounded screen-space environment-light approximation, not a complete spherical HDR environment. Both light contributions use the actual Galaxy texture; there are no independent flashing lights, per-frame model renders, extra WebGL contexts or CPU readbacks. Forced colors disables this light along with the sky. The additional target and override normal material are disposed with the scene.

After four consecutive presentation intervals above 150ms, the background lowers its pixel budget by 40%, down to 125,000 pixels. This affects only the Galaxy texture; the model and live text keep their own resolution. Suspended time does not count as slow rendering. Head input retains its 110ms damping with a 120ms maximum integration step so low frame rates do not artificially prolong settling.

The hero accepts passive pointer/touch input; links, form controls and navigation never trigger the click warp. Pausing freezes flight and releases repulsion. The hero reveal, offscreen and hidden states suspend GPU work, and resuming does not integrate hidden elapsed time. Reduced motion uses the established static 2D approximation without requesting the model or a WebGL context; forced colors hides the stars.

Validation of the starlight/arrival refinement on 2026-11-15: Astro check and the production build passed. All 34 browser tests covering the alien, Galaxy, lighting, scroll exit and clock passed. The lighting test changes the source sky over cached sphere geometry and confirms directional changes on its surface; the GPU uniform audit confirms a monotonic small-to-large arrival and no replay after resize. Unit tests: 84 passed, with one existing unrelated `brand-assets.test.ts` failure because the committed white favicon does not contain the cobalt color expected by that test. The homepage favicon is outside this refinement.

Visual evidence for the earlier dimmed-star refinement is in `artifacts/galaxy-refinement/`: desktop/mobile captures, the small/approaching/full arrival frames, and identical-frame lit/unlit comparisons. That homepage lighting comparison changed 309,952 pixels, with a mean difference of 1.12 per color channel among changed pixels. Those captures predate the latest brightness restoration. Desktop and mobile renders were inspected; no physical-device test is implied.
